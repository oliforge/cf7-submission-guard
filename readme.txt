Configurable server-side submission rules and lightweight logs for Contact Form 7.

== Description ==

CF7 Submission Guard validates Contact Form 7 submissions before mail is sent. It can enforce field length rules, block URLs and email-like content, validate country values, block email domains, rate-limit by IP, require a minimum completion time, detect duplicate messages, validate a configured consent field, and keep lightweight security logs without storing submitted message contents.

== Installation ==

1. Install and activate Contact Form 7.
2. Upload and activate CF7 Submission Guard.
3. Open Settings > CF7 Submission Guard and configure field names/rules.
